# رهگیر مطالعه کنکور

PWA آفلاین برای پیگیری مطالعه، تست و خواب. داده فقط روی دستگاه و در IndexedDB می‌ماند.

## استقرار روی GitHub Pages

محتوای همین پوشه را در ریشهٔ ریپازیتوری (یا پوشهٔ منتشرشده) بگذارید:

- `index.html`
- `style.css`
- `app.js`
- `db.js`
- `timer.js`
- `charts.js`
- `share.js`
- `shamsi.js`
- `sw.js`
- `manifest.json`
- `icons/icon-192.png`
- `icons/icon-512.png`

سایت باید از HTTPS سرو شود. بعد از اولین بارگذاری، Chrome روی اندروید گزینهٔ نصب / Add to Home Screen را نشان می‌دهد.

## لینک فقط‌خواندنی

لینک اشتراک، یک snapshot رمزگذاری‌نشدهٔ همین روز است که داخل hash آدرس قرار می‌گیرد. سرور، انقضا یا ابطال واقعی ندارد؛ هرکس لینک را داشته باشد گزارش را می‌بیند. حذف لینک فقط با ندادن آن به دیگران ممکن است.

## پشتیبان

از بخش مدیریت می‌توانید JSON پشتیبان بگیرید یا بازیابی کنید. تصویر تمرکز داخل این JSON نیست.
